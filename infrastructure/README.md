# Infrastructure

This directory will contain infrastructure-as-code for DataSense.

It is intentionally empty in Phase 1.

## Planned contents

- `docker/` – Dockerfiles for each service.
- `docker-compose.yml` – Local development orchestration (PostgreSQL, Redis, API, web).
- `.github/workflows/` – CI/CD pipelines (lint, test, build, deploy).
