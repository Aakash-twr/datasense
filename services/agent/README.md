# DataSense Agent Service

This service will house the AI agent layer powered by **LangGraph** and **LangChain**.

It is intentionally empty in Phase 1.

## Planned capabilities

- Multi-step AI reasoning chains powered by LangGraph.
- SQL generation from natural language using Google Gemini.
- Automatic chart recommendation and configuration.
- Statistical insight extraction.
- Business intelligence report generation.
- Transparent agent execution history.

## Implementation target: Phase 3
