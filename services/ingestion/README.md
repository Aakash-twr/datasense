# DataSense Ingestion Service

This service will handle dataset ingestion, validation, and storage.

It is intentionally empty in Phase 1.

## Planned capabilities

- CSV, Excel, JSON, and Parquet file parsing.
- Schema inference and column type detection.
- Data quality validation and profiling.
- Columnar storage with DuckDB and Parquet.
- PostgreSQL metadata catalogue.
- pgvector semantic indexing of dataset schemas.

## Implementation target: Phase 2
