# Reporting & Exports

DataSense compiles multi-agent findings, Polars calculations, Recharts charts, and SQL provenance IDs into structured business intelligence documents persisted in `analysis_reports`.

---

## 1. Eleven-Section Report Structure (`ReportContent` & `ReportViewer.tsx`)

1. **Executive Summary** — Concise synthesis of key quantitative takeaways.
2. **Datasets Analyzed** — Versioned datasets and table counts included in run scope.
3. **Analytical Objectives** — Original request and Supervisor planning rationale.
4. **Key Findings** — Grounded findings citing verified `query_run` evidence IDs.
5. **Statistical Analysis** — Deterministic counts, sums, means, medians, and standard deviations.
6. **Data Quality Observations** — Severity-tagged completeness and PII protection notes.
7. **Trends and Comparisons** — Period comparisons, category rankings, and IQR anomalies.
8. **Recommended Visualizations** — Embedded interactive Recharts specifications (`VisualizationGallery.tsx`).
9. **Business Recommendations** — Actionable next steps tied to observed findings.
10. **Limitations** — Dataset scope boundaries, sample sizes, and caveats.
11. **Supporting Queries and Evidence** — Traceable links back to executed `query_run_id` records.

---

## 2. Export & Sharing Capabilities

- **Report Library (`/reports`)**: Searchable and filterable organization-wide repository by project and workflow mode, displaying creation/update metadata and author (`ReportsPage.tsx`).
- **Download Markdown (`.md`)** & **Copy Markdown**: Exports structured Markdown generated by `_render_markdown()` (`report_node.py`).
- **Print-Ready Styling**: `@media print` CSS rules inside `apps/web/src/styles/globals.css` strip navigation sidebars and headers for crisp PDF/paper printing.
